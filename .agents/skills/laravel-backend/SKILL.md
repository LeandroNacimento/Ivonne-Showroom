# Laravel Backend Skills

Ajusta logica de controladores y modelos Eloquent respetando validacion estricta y consistencia transaccional.

## Instrucciones

1. **create_laravel_component**: Crea o motiva componentes Blade sin alterar el diseno.
2. **modify_controller_logic**: Ajusta controladores con Policies y Middleware.
3. **update_model_logic**: Agrega logica de dominio (imagen principal, stock, estados).
4. Al modificar archivos PHP, deja imports, orden y estilo compatibles con Laravel Pint y con el action del repositorio.
