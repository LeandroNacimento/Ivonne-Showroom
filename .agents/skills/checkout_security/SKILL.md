# Checkout & Security Skills

Gestiona la lógica del carrito de compras, el mensaje final de WhatsApp y los controles de acceso y validación.

## Instrucciones

1. **update_cart_logic**: Modifica lógica basada en sesión y validación.
2. **generate_whatsapp_message**: Construye mensajes humanos y claros.
3. **validate_inputs**: Define reglas estrictas para formularios.
4. **apply_access_control**: Configura Policies y Middleware.
