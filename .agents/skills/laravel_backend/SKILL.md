# Laravel Backend Skills

Ajusta lógica de controladores y modelos Eloquent respetando validación estricta y consistencia transaccional.

## Instrucciones

1. **create_laravel_component**: Crea o motiva componentes Blade sin alterar el diseño.
2. **modify_controller_logic**: Ajusta controladores con Policies y Middleware.
3. **update_model_logic**: Agrega lógica de dominio (imagen principal, stock, estados).
